## ทฤษฎีโดยย่อ

- **ความถี่ (f)** = จำนวนรอบต่อวินาที (Hz) · **คาบ (T)** = เวลาต่อหนึ่งรอบ → `T = 1/f`
  - 220 Hz → T ≈ 4.545 ms · 440 Hz → T ≈ 2.273 ms
- **แอมพลิจูด (A)** = ขนาดการแปรผัน ไม่ส่งผลต่อคาบ · การเปลี่ยนระดับ `ΔL = 20·log10(A2/A1)` dB เช่น 0.6 → 0.3 = −6.02 dB
- **Timbre** ขึ้นกับสัดส่วนฮาร์มอนิก (2f₀, 3f₀, …) และรูปซองสัญญาณ (ADSR) — เสียงที่ f₀ เท่ากันจึงฟังต่างกันได้
- **เปอร์เซ็นต์ความคลาดเคลื่อน** = `|ค่าวัด − ค่าทฤษฎี| / ค่าทฤษฎี × 100`

### ขั้นที่ 2 — สร้างโทนและวัดคาบ (30 นาที · ห้ามเปิด AI)

<details>
<summary>🔑 โค้ดเฉลยสำหรับตรวจเทียบ (เปิดดูหลังทำรอบที่ 3 แล้วเท่านั้น)</summary>

```python
import numpy as np
from scipy.io import wavfile
import matplotlib.pyplot as plt

fs = 48000                      # sample rate (Hz)
dur = 1.0                       # วินาที
t = np.arange(int(fs * dur)) / fs

def tone(f, amp=0.3, shape="sine"):
    ph = 2 * np.pi * f * t
    if shape == "sine":
        x = np.sin(ph)
    elif shape == "square":
        x = np.sign(np.sin(ph))
    elif shape == "sawtooth":
        x = 2 * ((f * t) % 1.0) - 1
    x = amp * x
    fade = int(0.01 * fs)                       # fade 10 ms กันเสียงคลิก
    env = np.ones_like(x)
    env[:fade] = np.linspace(0, 1, fade)
    env[-fade:] = np.linspace(1, 0, fade)
    return (x * env).astype(np.float32)

for shp in ("sine", "square", "sawtooth"):
    wavfile.write(f"tone_220Hz_{shp}.wav", fs, tone(220, 0.2, shp))

seg = slice(int(0.1 * fs), int(0.11 * fs))      # 10 ms หลังช่วง fade
for shp in ("sine", "square", "sawtooth"):
    plt.plot(t[seg] * 1000, tone(220, 0.2, shp)[seg], label=shp)
plt.xlabel("time (ms)"); plt.ylabel("amplitude"); plt.legend(); plt.grid(True)
plt.savefig("w01_shapes.png", dpi=150)
print("T(220 Hz) =", 1000 / 220, "ms")
```

หมายเหตุ: square และ sawtooth ที่สร้างแบบนี้มีฮาร์มอนิกสูงกว่า fs/2 จึงเกิด aliasing เล็กน้อย — เราจะเข้าใจเรื่องนี้ในสัปดาห์ที่ 2 (Audacity มีตัวเลือก “Square, no alias” ด้วยเหตุผลเดียวกัน)

## คำถามท้ายการทดลอง

1. คาบที่วัดได้ของ 220 Hz และ 440 Hz คลาดเคลื่อนจากทฤษฎีกี่เปอร์เซ็นต์ สาเหตุของความคลาดเคลื่อนมีอะไรบ้าง และการวัด 10 รอบช่วยลดความคลาดเคลื่อนได้อย่างไร
2. จากตารางที่ 2 สรุปความสัมพันธ์ระหว่างแอมพลิจูด คาบ และความดังที่ได้ยิน พร้อมอ้างอิงตัวเลข dB
3. เสียงในชุดที่เลือก (ขั้นที่ 4) มี f₀ ใกล้เคียงกันแต่ฟังต่างกันอย่างไร อธิบายด้วยแนวคิดฮาร์มอนิกและ envelope
4. ในขั้นที่ 6 ถ้าไม่ปรับระดับให้เท่ากันก่อน ผลการทายจะเชื่อถือได้หรือไม่ เพราะอะไร
5. AI ตอบหรือเขียนโค้ดผิดตรงไหนบ้าง และนักศึกษาตรวจพบได้อย่างไร (ถ้าไม่พบข้อผิดพลาด อธิบายว่าตรวจอย่างไรจึงมั่นใจ)
