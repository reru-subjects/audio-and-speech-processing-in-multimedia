## ทฤษฎีโดยย่อ

- **Sample rate (fs)** = จำนวนตัวอย่างต่อวินาที · **ความถี่ไนควิสต์** `f_N = fs/2` = เพดานความถี่ของไฟล์
- ความถี่ที่สูงกว่า `f_N` และเข้าสู่การสุ่มโดยไม่ถูกกรอง จะพับเป็น **เอเลียส** `f_alias = |f − k·fs|` (เลือก k ให้ผลอยู่ใน 0 … fs/2)
- การ **resample ที่ถูกต้อง** = กรองต่ำผ่าน (LPF) ก่อน แล้วจึงลดจำนวนตัวอย่าง — Audacity (Tracks → Resample) และ `scipy.signal.resample_poly` ทำให้อัตโนมัติ แต่ `x[::3]` ไม่กรอง
- **Bit depth (B)** → 2^B ระดับ · SQNR ทางทฤษฎี ≈ 6.02·B + 1.76 dB
- **ขนาดข้อมูล PCM** (ไม่รวมส่วนหัวไฟล์) = `fs × B × ช่อง × วินาที ÷ 8` ไบต์

```python
# --- รอบที่ 1: aliasing 6 kHz @ 8 kHz ---
import numpy as np
import matplotlib.pyplot as plt

f_in, fs = 6000, 8000
t = np.linspace(0, 1.5e-3, 3000)            # "เวลาต่อเนื่อง" ความละเอียดสูง
n = np.arange(0, 1.5e-3 + 1e-12, 1 / fs)    # เวลาของแต่ละตัวอย่าง

x_true  = np.cos(2 * np.pi * f_in * t)
x_samp  = np.cos(2 * np.pi * f_in * n)
f_alias = abs(f_in - round(f_in / fs) * fs) # |f - k*fs|
x_alias = np.cos(2 * np.pi * f_alias * t)

plt.figure(figsize=(9, 3.5))
plt.plot(t * 1e3, x_true, lw=1, label=f"input {f_in} Hz")
plt.plot(t * 1e3, x_alias, "--", lw=2, label=f"alias {f_alias} Hz")
plt.plot(n * 1e3, x_samp, "o", ms=8, label=f"samples @ {fs} Hz")
plt.xlabel("time (ms)"); plt.legend(loc="lower right"); plt.grid(True)
plt.title(f"Aliasing: {f_in} Hz sampled at {fs} Hz -> {f_alias} Hz")
plt.savefig("w02_aliasing.png", dpi=150, bbox_inches="tight")
print("alias =", f_alias, "Hz")
```

```python
# --- รอบที่ 3: Alias Hunter ---
import numpy as np
from scipy.signal import chirp, resample_poly
from scipy.io import wavfile

fs = 48000
t = np.arange(int(fs * 4)) / fs
x = 0.3 * chirp(t, f0=50, f1=20000, t1=4, method="linear")   # กวาด 50 Hz → 20 kHz

y_naive = x[::3]                            # ❌ ข้ามตัวอย่าง ไม่กรอง
y_good  = resample_poly(x, up=1, down=3)    # ✅ กรองก่อนแล้วลดอัตรา

wavfile.write("chirp_48k.wav", fs, x.astype(np.float32))
wavfile.write("chirp_16k_naive.wav", 16000, y_naive.astype(np.float32))
wavfile.write("chirp_16k_resample_poly.wav", 16000, y_good.astype(np.float32))
```

แนวคำตอบ: ในไฟล์ `naive` หลังวินาทีที่ ~1.6 (เกิน 8 kHz) จะได้ยินเสียงกวาด **ย้อนลง** เพราะความถี่พับกลับรอบ 8 kHz ส่วนไฟล์ `resample_poly` เสียงจะเงียบลงหลังผ่าน 8 kHz เพราะถูกกรองออก

## คำถามท้ายการทดลอง

1. ส่วนต่างระหว่างขนาดไฟล์จริงกับทฤษฎี (ตารางที่ 4) มาจากอะไร และทำไมจึงใกล้เคียงกันทุกไฟล์
2. ความถี่สูงสุดที่เห็นในสเปกตรัมของไฟล์ 16 kHz และ 8 kHz สัมพันธ์กับ f_N อย่างไร ทำไมจึงไม่มีเอเลียสในไฟล์ที่ resample ด้วย Audacity
3. พยัญชนะใดได้รับผลกระทบมากที่สุดเมื่อลดเป็น 8 kHz เชื่อมโยงกับย่านความถี่ในตารางที่ 1.5 ของสัปดาห์ที่ 1
4. จากรอบที่ 3 ของ Prompt Lab อธิบายด้วยสูตร `|f − k·fs|` ว่าทำไมเสียง chirp ในไฟล์ `naive` จึงกวาดย้อนลง
5. ถ้าเปลี่ยนจาก 24 บิตเป็น 16 บิต SQNR ทางทฤษฎีลดลงกี่ dB และควรใช้เทคนิคใดเมื่อแปลง
6. AI ผิดพลาดตรงไหนบ้าง หรือถ้าไม่ผิด นักศึกษาตรวจอย่างไรจึงมั่นใจ
